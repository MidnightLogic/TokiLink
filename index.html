Brave Browser Bluetooth Setup

Brave disables Web Bluetooth by default for privacy. Enable it in 3 quick steps:

1
Paste into Brave address bar:
brave://flags/#brave-web-bluetooth-api
2
Set Web Bluetooth API to Enabled
3
Tap/Click Relaunch at the bottom of Brave
Tip If already enabled, click the 🔒 icon in the address bar → Site settings → set Bluetooth to 'Ask' or 'Allow'.

1-Click Fast Sync Setup

Enable permanent device remembering in Chrome / Brave / Edge

By default, desktop browsers ask you to select your clock each time. Enabling this Chrome flag allows TokiLink to remember your clock permanently across reloads for instant 1-click sync without repeating the device chooser dialog.

1
Copy and paste this URL into your browser address bar:
chrome://flags/#enable-web-bluetooth-new-permissions-backend
2
Set Use the new permissions backend for Web Bluetooth to Enabled.
3
Click the blue Relaunch button at the bottom of your browser window.
Brave Browser Users

In Brave, enable both the Web Bluetooth API and the New Permissions Backend flags:

brave://flags/#brave-web-bluetooth-api
brave://flags/#enable-web-bluetooth-new-permissions-backend
